# ClaimPilot engineering guide

The original starter exercise has been replaced by a working expense application. Read [architecture](../docs/ARCHITECTURE.md), [project rules](../CLAUDE.md), and [setup/demo instructions](../README.md).

All future changes must preserve actor-bound server authorization, integer minor-unit money, deterministic policy decisions, private receipts, confirmed consequential AI actions, and the claim state machine. Run the documented tests and build before delivery.
